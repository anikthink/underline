Nightstand Brand

One idea: the small pool of lamplight where the book you're reading waits. The brand is a night-blue room with one warm light in it, and that warm light is the same colour the app uses for Reading. Everything else stays quiet so the books can be loud.

01The mark

macOS shape and grid, with the default, dark and tinted versions that macOS 26 asks for. The default is already a night scene, so dark mode only deepens it.

03Wordmark

Literata Semibold, the same serif as the reader. The dot on the i is the lamp: the only warm thing in the word.
