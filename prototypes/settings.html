Nightstand Settings

⌘, opens a separate Settings window, like any Mac app. There are six tabs, and most of what's in them was already decided in the other prototypes: where the library lives, reader defaults, Markdown export for Obsidian, and how each device brings things back. Every change applies straight away, so there's no Save button.

01General

Dark. Theme, what opens first, and Open Library, with a plain statement of what's sent. Download covers depends on lookups, so it greys out when they're off.

02Library

Light. One folder holds everything, and the path shows exactly where a book's file will go. Adding copies by default; watching Downloads is off until you turn it on.

03Reader

Dark. Defaults for every book, with a live page at the top. Theme matches the app until you pick one, so the Reader follows Light and Dark.

04Notes

Light. Export to a folder in an Obsidian vault and keep it up to date. The preview is the actual file that gets written, and changes as you change the options.

05Devices

Dark. Each device Nightstand has seen, with the same Automatically / Ask first / Never choice as its page. Shortcuts is the sixth tab.

How it behaves

  1. Changes apply as you make them. No Save or Cancel. The Theme and Reader settings change what's on screen behind the window straight away.
  2. Each setting says what it does. The description under a setting changes with its value, so it always describes what will happen now, not both options.
  3. The same setting lives in one place. A device's bring-in choice shows on its page and here, and they're the same setting. Reader changes made while reading only affect that book; these are the defaults.
  4. Nothing here is required. Every default works for someone who never opens Settings: copy books in, Literata at 19 pt, match the app's theme, highlights in automatically, no export until a folder is chosen.

Decided

  1. The four labels are fixed. Quote, Idea, Question and Disagree can't be renamed, so filters and exports mean the same thing in every book.
  2. Export starts off. A new library has no export folder, so the Notes tab shows a Choose folder button and nothing is written. The frame above shows it after a folder has been chosen.
