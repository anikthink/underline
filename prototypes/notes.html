Nightstand Notes

Every underline from every book, in one place in the library. Revisit brings back a different passage you underlined over a month ago each time you open Notes, and fills the app's empty states. The list below can be grouped by date, book or label, and filtered by label or by search.

01Recent

Dark. Revisit at the top (a new pick each time you open Notes, never the one you saw last), then the newest underlines grouped by day. Hover a row, or move to it with J/K, to see its actions.

02By book

Light. Each book shows its status and a bar of its labels, so it's clear at a glance which books you argued with.

03Search and filter

Search covers quotes, your notes and book titles. The label chips combine with it; here, "pride" filtered to Quote and Idea.

04Export to folder

Light. One Markdown file per book, with frontmatter and labels as tags, so the folder drops straight into an Obsidian vault. Filters don't apply here: the folder is a full copy.

05Empty states

Dark. The library's Reading view with nothing in progress. Instead of a blank page, it offers the next step and a passage from your underlines. The Notes "No underlines match" state does the same.

Decided

  1. Revisit frequency. A new passage each time you open Notes, never the same one twice in a row. R or "Another" picks again.
  2. Where Revisit lives. On Notes, and on empty states: an empty library view (frame 05) and a search with no matches. Empty states use a smaller card.
  3. Export. Two options under Export. Copy as Markdown copies what's on screen, filters included. Export to folder writes one file per book; with "Keep up to date" on, Nightstand rewrites those files when you add or change an underline. It never touches files it didn't create.
