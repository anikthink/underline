Nightstand Adding books

Drop files anywhere in the window. Nightstand copies them into the library, reads what it can from each file, and fills in the rest from Open Library. Most books go straight in. You only see the ones that need a decision.

Data
Thirteen files. Covers, years and page counts are from Open Library; the four Odyssey translations are real editions, looked up by ISBN
Try
Drag real ebook files onto any frame: they're looked up on Open Library live. Replay the import in 03, pick an edition in 04, settle the duplicate in 05
01First run

Light. An empty library is one large drop target. A calibre library on the same Mac is offered as a one-click import, and the optional watched folder can be switched on here or in Settings.

02Dropping files

Dark. Dragging files over the window shows how many will be added and in which formats, before you let go.

03Importing

Dark. Three files at a time: read the file, look it up, add it. The import keeps going in the sidebar if you leave this page. Paused at 8 of 13; Replay runs it from the start.

04Choosing an edition

Light. When it's done, only four of the thirteen files need you. Here Nightstand can't tell which Odyssey translation the file is, so it compares opening lines and suggests one.

05Already in your library

Dark. A different edition of a book you're reading. You choose whether it replaces the file, sits beside it, or is skipped. Your place and underlines follow the book.

06Back in the library

Light. New books land in Not started, marked New until you open them. A new format joins the book you already had.

How it behaves

  1. Goes straight in: a file with a clear title and author, or an ISBN, that matches one Open Library record. So does a new format of a book you already have, which joins that book.
  2. Skipped without asking: a file that's byte-for-byte one you already have. It's counted in the summary, not listed.
  3. Needs a look: several plausible editions, details guessed from the first page, a different edition of a book already in the library, or no match at all.
  4. Can't be added: DRM-protected files and files that aren't ebooks. Each says why.

Decided

  1. Files are always copied into ~/Books/Nightstand, so the library is one folder you can back up. You can change where that folder is, but there's no "leave files in place" option.
  2. Watched folder is an optional setting, off by default. When it's on, new ebooks that land in the chosen folder are added the same way as dropped files, and anything that needs a look waits in the sidebar.
  3. Books from calibre arrive as Not started. calibre tags and columns don't set the reading status.
